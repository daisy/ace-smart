If the publication has links, inputs, or controls with visible labels (i.e., that are visually rendered), the accessible name of the control must be the same as the visible text. For example, the accessible name should not have additional text that is hidden visually as this prevents text matching for speech input users.

The name of an input or control is defined in the label element for it, or, if not specified, in an aria-label, title, or aria-labelledby attribute on the element.

Note: This success criterion does not apply to inputs, links, and controls without visible labels (i.e., where the accessible name can only be computed from non-visible text).
